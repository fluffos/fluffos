# FluffOS RFCs

Design proposals for changes large enough to need agreement before code:
new language or driver mechanisms, or changes to how mudlibs interact with the
driver. Each RFC is a directory `NNNN-short-name/` with a `README.md` and any
supporting material (probes, benchmarks). RFCs are discussed in their pull
request; an accepted RFC is merged here, and its user-facing documentation
moves to `docs/` when it is implemented.
