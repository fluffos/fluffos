# FluffOS

FluffOS 是高性能 **LPMUD 驱动**（游戏引擎）：**LPC** 编译器与虚拟机、网络服务（Telnet / WebSocket / TLS），以及 mudlib 可调用的数百个内置函数（**efun**）。它是仍在维护的 **MudOS** 后继。

在搜 **MudOS**、**LPMUD** 或 **LPC**？先看 [MudOS、LPMUD 与 LPC](/zh-CN/lpmud)。

它**不是**完整游戏。**Mudlib**（一棵 LPC 文件树）才是游戏。先选一份
（Dead Souls、Lima、泥潭、侠客行，或 [fluffos/mudlibs](https://github.com/fluffos/mudlibs) 里的游戏），再把驱动指过去。

:::tip[先跑起来]
**人类：**[选一份 mudlib 并启动](/zh-CN/start)。

**语言模型：**[https://www.fluffos.info/llm](https://www.fluffos.info/llm)
——助手必须**先问用哪份 lib**再克隆。
（[llms.txt](/llms.txt) · [AGENTS.md 模板](/zh-CN/mudlib-agents)）。
:::

当前版本是 `master` 分支（CMake；Ubuntu / macOS / Windows MSYS2 / WebAssembly）。参见 [GitHub Releases](https://github.com/fluffos/fluffos/releases)。

## 三层结构

| 层 | 是什么 |
|---|---|
| **LPC** | 面向对象、类 C 的语言。房间、物品、玩家都是对象。 |
| **驱动（FluffOS）** | 编译并运行 LPC，管理连接、数据库和 efun。 |
| **Mudlib** | 你的游戏：登录、命令、房间、战斗、策略。换 mudlib，二进制可以不变。 |

组织下的全部仓库（mudlib、VS Code、转码工具等）：[FluffOS 生态](/zh-CN/ecosystem)
（`fluffos/fluffos`、`fluffos/dead-souls`、`fluffos/nt7`、`fluffos/fluffos-vscode` …）。

**MudOS** 是已停止维护的前身。**LPMUD** 是驱动 + mudlib 分层。**LPC** 是语言。
术语表：[MudOS、LPMUD 与 LPC](/zh-CN/lpmud)。

## 特性

- 用 CMake 在 Ubuntu、macOS、Windows（MSYS2/MinGW64）上构建，另有 WebAssembly 目标。
- 原生 UTF-8（含 Emoji）与透明的输入/输出转码。
- 同一进程上的 Telnet、WebSocket、TLS；`src/www` 内置网页客户端。
- 默认 SHA-512 crypt；SQLite / MySQL / PostgreSQL；异步文件与数据库 I/O。
- LPC 原生 Promise 与 `async` / `await`。
- 热重载：`recompile_object()` 更新正在运行的程序及其所有 clone。
- LPC `int` 恒为 64 位，`float` 为 C `double`。
- 兼容 MudOS mudlib；请升级，不要继续使用已停止支持的 v2017。
